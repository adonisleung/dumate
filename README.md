# dumate

每日自动整理的 AI 工具精选：Agent Skill / 插件、MCP 服务器、生图 Prompt、国内社区玩法。

每天 **06:30** 与 **18:30**（Asia/Shanghai）自动搜集一次，去重后增量追加到对应分类文件；无新增则不产生提交。

## 条目格式

名称 — Star → 说明 → 亮点 / 注意 → 链接 → 收录日期。同一项目只保留一条，Star 按采集当日更新。

## 数据口径

- GitHub 项目的 Star 与最近提交时间取自 GitHub API，并标注采集日期；
- 国内平台条目为公开文章 / 聚合页的转述，均附原文链接；小红书站内需登录，不做直接抓取。
