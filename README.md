## 条目格式

名称 — Star → 说明 → 亮点 / 注意 → 链接 → 收录日期。同一项目只保留一条，Star 按采集当日更新；已收录条目只刷 Star 并追加「更新」行，不重复插入。

## 数据口径

- GitHub 项目的 Star 与最近提交时间取自 GitHub API，并标注采集日期；
- 国内平台条目为公开文章 / 聚合页的转述，均附原文链接；小红书站内需登录，不做直接抓取。
